## الميزات العاملة

- قيادة Arcade، فرامل وانجراف ونيترو، منافسون، ثلاث لفات ونتائج وإعادة سباق.
- لوحة مفاتيح، يد تحكم محاكاة، ولمس متعدد أفقيًا وعموديًا؛ Interpolation وكاميرا المطاردة محفوظان.
- العالم الساحلي والسيارات الثماني والمرآب والتخصيص والمضامير السابقة محفوظة.
- صوت محرك إجرائي ونيترو/انجراف، مع تعليق الصوت في الخلفية واستئنافه بتفاعل اللاعب.
- حفظ تلقائي محلي version 2: عملات، ترقية، ملكية سيارات وطلاء، إنجازات وأرقام قياسية وأشباح، الإعدادات واختيار السيارة/المضمار، وآخر 20 نتيجة شخصية.
- ترحيل البيانات القديمة، جيل حفظ سابق، تصدير/استيراد، وتعافٍ من جيل تالف أو استيراد صريح عند تلف الجيلين مع أرشفة الأصل.
- ملف ضيف محلي اختياري. **ليس حسابًا سحابيًا، ولا توجد مزامنة سحابية مفعلة.**

## بيئة القياس والقيود

اختُبر Linux مع Node 24، وChromium Debian 156.0.8078.79 وChrome for Testing
156.0.8078.80 باستخدام **SwiftShader**. CI مثبت على Ubuntu 24.04 ونسخة
المتصفح نفسها مع تحقق SHA-256. لا GPU فعلي أو iPhone/iPad/Android فعلي.
WebKit غير مثبت؛ لذلك **Safari/WKWebView لم يُختبرا**. Safari وChrome على
الهواتف أهداف توافق للحزمة، وليسا منصتين معتمدتين ميدانيًا بهذه النتائج.

في أربعة سباقات تحمل: 119 geometry و10 textures و24 shader programs ثابتة؛
heap بعد GC انتقل من 7.899 إلى 8.042MiB. هذا فحص محدود، لا إثبات ضد كل تسرب.
في محاكاة 5.5 ثانية بالخلفية: صفر عروض جديدة وصفر حفظ دوري؛ لا قياس لواط البطارية.

ظل عدد draw calls للمؤثرات مطابقًا قبل/بعد عند قياس طور الظلال نفسه.
الجسيمات الجديدة أضافت 7,800 بايت ثابتة على CPU و3,600 بايت لسمات GPU.
قياس CPU المنفصل: المتوسط 0.00287→0.00516ms وP99 0.02988→0.04433ms.
ليست هذه FPS أو أزمنة GPU؛ لا ادعاء تحقيق 60 أو 120 FPS على أجهزة فعلية.

## المشكلات والحدود المتبقية

1. يلزم اختبار Safari وأجهزة iOS/Android فعلية قبل اعتماد توافقها أو توزيع أوسع: الصوت بعد تبديل التطبيقات، اللمس، الحرارة، ضغط الذاكرة والاستيراد/التصدير.
2. الحفظ مرتبط بالمتصفح وorigin. حذف بيانات الموقع قد يحذفه؛ التعديلات التي لم تُؤكَّد محفوظة قد تضيع عند إنهاء العملية. يُنصح بنسخة تصدير خارج المتصفح.
3. إذا تلف الجيلان مجددًا مع وجود أرشيف تلف مختلف سابق، تُرفض الكتابة لحماية الأصل؛ قد تتطلب الحالة تصدير الأرشيف وصيانة التخزين يدويًا مع الاحتفاظ بنسخة سليمة خارج المتصفح. لا استعادة سحرية من بيانات تالفة بلا نسخة صالحة.
4. تنبيه Vite لحجم حزمة Three.js فوق 500kB غير مضغوطة باقٍ؛ البناء ناجح والملفات مخزنة للعمل دون اتصال. لا تحسين تخميني جديد قبل قياس جهاز فعلي.
5. الاختبارات ليست تغطية لكل طقس وصعوبة ومضمار، ولا جلسة سماع بشرية أو اختبار يد تحكم فعلية طويل المدة.

هذه القيود موثقة للمراجعة ولا تعادل اعتماد المتاجر أو جميع الأجهزة. لم يُخفَّف
اختبار لإخفاء خلل: عولج سباق تأكيد الحفظ، وثُبت المتصفح، وقورنت مرحلتا الظلال
منفصلتين. المرجع التاريخي والأرقام الدقيقة لم تُعدّل.

## الحزمة والتجربة

نزّل artifact `sunset-rush-3-review-…` من آخر **push workflow ناجح لنفس commit**،
ثم فك ZIP الداخلي `sunset-rush-3-beta-….zip`. يتضمن `BUILD_INFO.json`،
`SHA256SUMS`، `REVIEW.md`، هذا التقرير و`TEST_RESULTS.json` وإشعارات التراخيص.
Artifact تنزيل للمراجعة فقط، وليس موقع لعبة منشورًا أو GitHub Release.

داخل المجلد المستخرج شغّل:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

افتح `http://localhost:8080/`. لا تستخدم `file://`. الهاتف يحتاج HTTPS موثوقًا؛
نشر رابط إنترنت أو تعريض خادم للإنترنت ما زال يتطلب الموافقة. افتح اللعبة أولًا
واترك التحميل وService Worker يكتملان قبل تجربة إعادة الفتح دون اتصال.

النتائج الخام والصور في المستودع تحت `docs/v3/beta` و`docs/v3/phase3`؛
تفصيل المقارنة في `docs/v3/EFFECTS_REVIEW.md`، وخطوات التشغيل في
`docs/v3/REVIEW_GUIDE.md`.
