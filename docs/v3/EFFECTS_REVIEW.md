# مراجعة المؤثرات وإصلاح المقارنة

المقارنة من `30b20b4` إلى دفعة المؤثرات الحالية على فرع المرحلة الثالثة.
حالة السيارة والكاميرا والتحكم والبيئة والبذرة ثابتة، بدقة 960×600 وDPR 1
وجودة Medium. الصور لقطات فعلية من Chromium، وليست صورًا مولدة.

- [دخان قبل](phase3/effects/drift-before.png) / [بعد](phase3/effects/drift-after.png).
- [نيترو قبل](phase3/effects/nitro-before.png) / [بعد](phase3/effects/nitro-after.png).
- [شرارات قبل](phase3/effects/sparks-before.png) / [بعد](phase3/effects/sparks-after.png).

أُضيف interpolation لمواضع الجسيمات وحجمها وشفافيتها، مستقل عن بيانات
المحاكاة. إعادة استخدام خانة في التجمع لا تصل جسيمًا جديدًا بموقع قديم.
الدخان يتمدد ويرتفع ويتبدد، مع تموج بسيط في الجودة الأعلى. النيترو والشرر
أصبحا ممتدين باتجاه السرعة مع نواة مضيئة. Low وتقليل المؤثرات يتجاوزان
تموج الدخان ويحدان حجم النقطة إلى 48px مقابل 96px في الجودة الأعلى.
بقي تجمع الجسيمات محدودًا، وبقيت المادة والهندسة والملمس مشتركة دون إنشاء
موارد رسومية لكل إطار. لم تُضف معالجة Bloom أو post-processing.

## قياس الظلال دون إخفاء الاختلاف

القياس السابق قارن إطارًا يعيد رسم خريطة الظلال بإطار يستخدم الخريطة
المخزنة، فأظهر 137 مقابل 105 draw calls. لم يتغير جدول الظلال في اللعبة.
الاختبار يفرض طور التحديث قبل الالتقاط، ثم يقيس إطار التخزين أيضًا؛ ويؤكد
أن طور التحديث يضيف فعلًا عمليات رسم، وأن كل طور يطابق نظيره قبل التحسين.
المقارنة تستخدم مساواة دقيقة، بلا سماح بتفاوت أو تعديل لأرقام الفيزياء.

| المشهد | calls مع تحديث الظلال قبل/بعد | calls بخريطة مخزنة قبل/بعد |
| --- | --- | --- |
| انجراف | 137 / 137 | 105 / 105 |
| نيترو | 142 / 142 | 110 / 110 |
| شرارات | 142 / 142 | 110 / 110 |

المثلثات وعدادات geometries/textures/programs متطابقة أيضًا. فحص الشرارات
يستدعي مؤثر الاصطدام من أداة الاختبار ثم يحرك جسيماته 12 خطوة؛ لا يُعرض على
أنه تصوير اصطدام طبيعي. القيادة والدخان والنيترو تُولد بتحكم السيارة الفعلي.

## تكلفة الزيادة وحدود القياس

Node 24.22.1 على Linux، تجمع 150 جسيمًا، محاكاة 60Hz وعرض 120Hz،
600 callback للتسخين ثم 3000 عينة. هذا توقيت CPU للجسيمات فقط، دون الرسم:

| المقياس | قبل | بعد |
| --- | --- | --- |
| المتوسط ms | 0.00287 | 0.00516 |
| P95 ms | 0.01456 | 0.00762 |
| P99 ms | 0.02988 | 0.04433 |
| مصفوفات CPU bytes | 9,150 | 16,950 |
| سمات GPU bytes | 4,800 | 8,400 |

الـinterpolation أضاف 7,800 بايت ثابتة على CPU و3,600 بايت لسمات GPU.
تكلفة CPU زادت قليلًا؛ تغير P95 وحده ليس دليل تحسن أداء. لا تقيس هذه
النتائج زمن GPU أو البطارية، ولا تثبت 60/120 FPS على هاتف فعلي. SwiftShader
استُخدم لفحص التشغيل والموارد فقط. يلزم قياس fill rate والحرارة على الأجهزة.

الأدلة الخام: [قبل](phase3/effects/before.json)، [بعد](phase3/effects/after.json)،
[تكلفة CPU](phase3/effects/cpu.json). تشغيل المقارنة: `npm run test:effects`.


## تثبيت بيئة CI

تستخدم CI نسخة Chrome for Testing 156.0.8078.80 محددة في
`config/review-browser.json`، ويُتحقق من SHA-256 قبل استخراجها. صورة المشغل
Ubuntu 24.04 تدعم مكتبات Playwright المستخدمة. اختبار السباقات التاريخي
بقي كما هو ونجح على هذا المتصفح؛ لم يُعدل المرجع أو تُضف epsilon.

مرجع المؤثرات الخاص بـCI هو `phase3/effects/before-cft.json`، التُقط فعليًا
من checkout مستقل لـ30b20b4 بنفس المتصفح. المرجع والصور الأصلية باستخدام
Chromium Debian 156.0.8078.79 محفوظة أيضًا. يُختار المرجع قبل الاختبار وفق
بيئة التشغيل، وليس كبديل بعد الفشل. كل مقارنة ما زالت تشترط مساواة حالة
السيارة والكاميرا وعدادات الرسم في كل طور من الظلال.

لإعادة اختبار CI محليًا على Linux بعد تثبيت حزمة المتصفح:

```bash
python3 scripts/install-review-browser.py /tmp/sunset-review-browser
export CHROMIUM_PATH=/tmp/sunset-review-browser/chrome-linux64/chrome
export EFFECTS_BASELINE=docs/v3/phase3/effects/before-cft.json
npm run test:effects
```

يلزم أن يعمل خادم التطوير على 5173 عند تشغيل اختبار المتصفح.
