# Sunset Rush 3.0 — Phase 2

بدأ التنفيذ في 2026-11-08 من `c81bccd` على `feat/sunset-rush-visual-performance`. هذا تقرير مرحلي يُحدّث بعد كل دفعة. لا رفع للفرع، ولا تعديل لـPR #1 أو main، ولا نشر.

## A — الأداء قبل التطوير البصري

أُضيفت وحدة `performance.js` لقياس FPS ومتوسط زمن الإطار وP95/P99 من آخر 300 إطار، مع زمن CPU للمحاكاة وإرسال الرسم. تعرض الواجهة أيضًا draw calls والمثلثات وgeometries/textures/programs وذاكرة JS المستخدمة/حدها والمتبقي منها عندما يوفرها المتصفح. **VRAM المتاحة غير مكشوفة بهذه الواجهات وتبقى null**، ولا تُخلط مع heap.

الجودة: Low/Medium/High/Ultra/Auto، مع الحفاظ على معرّفات الإعدادات القديمة. Auto تستخدم دقة تكيفية من 60% إلى 100% من سقف المستوى، بمتوسط أسي ومهل مختلفة للصعود والنزول وhysteresis. تحديث حجم framebuffer مقنن إلى مرة كل 350ms وبخطوات صغيرة لتجنب إعادة تخصيصه كل إطار. الخيارات 30/60/120 هي ميزانية مستهدفة للتكيف، وليست فرضًا لمعدل أعلى من الشاشة أو ضمانًا له. توجد مفاتيح للظلال وتخفيف المؤثرات والدقة التكيفية.

التحسينات المنفذة:

- تجميع الديكور في خلايا مكانية ذات bounding volumes، بدل مجموعات تمتد عبر الجزيرة كلها.
- InstancedMesh للمباني، مع حدود لكل عنقود؛ Three r128 يعطل frustum culling للمجسمات المتكررة افتراضيًا ولا يحسب حدودها تلقائيًا.
- LOD بعيد للمنافسين في draw call واحد لكل سيارة، مع hysteresis. تفاصيل سيارات اللاعب والخصوم القريبين محفوظة. تحسين شكل الـLOD البعيد ضمن دفعة السيارات التالية.
- خامات Lambert للأجزاء غير المعدنية البعيدة، وإعادة استخدام خامة الأشرعة. بقي طلاء سيارات اللاعب PBR.
- تحديث الظلال بمعدل 24/30/60Hz حسب المستوى، وتعطيلها على Low؛ لا إعادة تخصيص لخريطة الظل إذا لم يتغير حجمها.
- إعادة استخدام المضمار الساحلي عند إعادة السباق بنفس إعداداته، بدل إنشاء هندسته وخاماته مرة أخرى. المسارات القديمة تبقى على مسار إعادة البناء الأصلي للحفاظ على عناصر اللعب القابلة للجمع.

### بيئة القياس وطريقته

Node 24.22.1، Chromium 156.0.8078.79، Linux، ANGLE/Vulkan **SwiftShader برمجي**. لا GPU فعلي ولا iPad أو هاتف فعلي. دقة 960×600، DPR=1، جودة Medium، نفس السيارة والمضمار والكاميرا وبذرة 135، محاكاة ثابتة أثناء القياس وطور الماء صفر.

لكل متغير: 3 تسخينات ثم 20 عينة `render + readPixels(1×1)`، مع طلب تحديث الظل كل مرة. العدادات تشمل تمريرة الظلال. القراءة ضرورية: تجربة `gl.finish` الأولى أعطت زمن إرسال الأوامر فقط فاستُبعدت. P95/P99 من 20 عينة تقديرات خشنة؛ P99 قريب من أكبر عينة. هذه قياسات مقارنة للمشهد البرمجي وليست FPS لعب على جهاز حقيقي.

| القياس المطابق | قبل c81bccd | بعد دفعة الأداء |
| --- | ---: | ---: |
| متوسط الرسم + readback | 491.78 ms | 357.59 ms |
| P95 | 555.40 ms | 480.50 ms |
| P99 | 715.40 ms | 541.70 ms |
| طلبات الرسم، مع الظل | 174 | 117 |
| المثلثات، مع الظل | 66,514 | 28,010 |
| geometries المُحمّلة في لقطة القياس | 126 | 83 |
| textures | 5 | 5 |
| تجهيز إعادة السباق، 5 عينات | 40.4–133.3 ms | 0.5–2.2 ms |

انخفض متوسط الرسم في هذه العينة نحو **27%**. الموارد المحملة تتأثر بالأجزاء المرئية وLOD؛ لا يمثل العدد تقدير VRAM. خلال عينات إعادة السباق بعد التحسين استقرت geometries عند 157 وtextures عند 5؛ كثرة الخلايا تزيد عدد موارد العالم الممكن تحميلها لكنها تقلل الرسم خارج المشهد وتمنع إعادة البناء.

فصل التكلفة قبل التعديل: تعطيل الظل خفّض المتوسط إلى 355.02ms؛ تعطيل الماء معه إلى 346.19ms؛ إخفاء السيارات مع إبقاء الماء إلى 280.79ms؛ نصف الدقة بلا ظل إلى 152.20ms. لذلك عولجت كلفة البكسلات والظلال والخامات/تفاصيل السيارات أولًا. قياس CPU لـ1200 خطوة محاكاة: 77.8ms قبل و85.0ms بعد في هاتين العينتين؛ **لا ندّعي تحسن CPU من هذه النتيجة**، ولم تُعدّل معادلات الفيزياء.

الدليل: [قبل](phase2/before-profile.json)، [بعد الأداء](phase2/performance-profile.json)، [كاميرا المقارنة](phase2/reference-view.json)، [اختبارات الأداء](phase2/performance-checks.json).

- تُعاد اختبارات المتصفح الـ34 كاملة بعد دفعات الرسوم، إلى جانب اختبارات الإنتاج والتوافق.

## B — العالم والسيارات والمؤثرات

### دفعة الساحل — 2026-11-09

- بحر يستخدم خريطة تموجات دورية أصلية تُخبز مرة واحدة، مع Fresnel وانعكاس اتجاه الشمس. Low يأخذ عينة واحدة بدل اثنتين. لا كاميرا انعكاس إضافية ولا ray tracing.
- سحب أصلية مرسومة إجرائيًا فوق تدرج السماء، تتحرك عبر UV. تحويل ألوانها يُخبز عند الإنشاء بدل تكراره لكل بكسل. إضاءة الغروب أكثر توازنًا.
- أوراق نخيل تتحرك في vertex shader مع تثبيت الجذور، ونسخة عمق مطابقة للظلال. حدود القطع توسعت لتشمل الحركة.
- قوارب متكررة تتمايل، و14 طائرًا في draw واحد، وحركة مرور بعيدة على الجسر. حركة هذه العناصر تستعمل uniforms وInstancedMesh ولا تعيد إنشاء geometry في كل إطار. Low وخيار تقليل المؤثرات يخفيان التفاصيل المتحركة الثانوية.
- تقويات للجسر، وعلامات اتجاه وأعمدة حافة الطريق ورغوة ساحلية. التفاصيل خارج حدود القيادة والتصادم.
- تحرير textures داخل uniforms وcustom depth materials عند تبديل المسار؛ اختبار متكرر بين الساحل والمسار الكلاسيكي أثبت ثبات الموارد بعد التسخين.

نجحت **23/23 وحدة اختبار** والبناء. نجحت ثلاثة فحوص متصفح جديدة: تغيّر 10,124 بكسل في عينة الحركة عند الزمن 0 ثم 4 ثوانٍ مع بقاء حالة السباق نفسها؛ استجابة خيار المؤثرات وLow؛ وثبات الموارد بعد تبديل المسارات. لم تظهر أخطاء JavaScript أو WebGL/shader. أُعيدت أيضًا فحوص الدفعة الستة، بما فيها سباق كامل مطابق لنتائج c81bccd: [النتيجة](phase2/world-checks.json).

عينة العالم الأولى عند نفس الكاميرا: 124 طلب رسم و29,329 مثلثًا و8 textures، ومتوسط 327.03ms في SwiftShader. لا تُقارن أزمنة جلستين مباشرة كضمان؛ يُعاد قياس مراجع c81bccd و3bab817 في بيئة الجلسة الحالية عند التسليم النهائي. [القياس](phase2/world-profile.json)، [اختبارات البيئة](phase2/environment-checks.json)، [لقطة الساحل](phase2/screenshots/world-matched.png).

### دفعة السيارات — 2026-11-09

النماذج الثمانية الحالية أصبحت بهياكل منحنية ذات normals ناعمة، زجاج مائل، جنوط بخمسة أذرع، أعمدة سقف ومصابيح وناشر خلفي. تعديلات المرآب باقية؛ شريط الطلاء يتبع سطح الهيكل. نموذج المنافس البعيد يستخدم نفس هيئة الجسم المبسطة وألوان رؤوس في طلب رسم واحد.

انعكاسات الطلاء والزجاج من cube map أصلية بستة أوجه مختلفة وPMREM تُجهز مرة واحدة؛ لا تصوير للمشهد مجددًا كل إطار. المواد Physical مع clearcoat، والطلاء المطفي ما زال متاحًا. انعكاسات ثابتة تقريبية وليست انعكاسات هندسة العالم في الزمن الحقيقي.

حركة إضافية صغيرة للتعليق وميل الهيكل من pose المستوفاة، دون تعديل Cannon أو الكاميرا أو تقدم السباق. خيار تخفيف المؤثرات يقلل هذه الحركة. يعاد وضع الهيكل عند الرجوع للمرآب.

نجحت **25/25 وحدة اختبار، و3/3 فحوص متصفح للسيارات، والبناء**. جُربت النماذج الثمانية وثلاث دورات تبديل؛ استقرت geometries/textures/programs بعد التسخين. التعليق يستجيب لانجراف فعلي، ومئة وأربع وأربعون عملية عرض لا تغير حالة السباق. [النتائج](phase2/vehicle-checks.json)، [قبل](phase2/screenshots/vehicle-before.png)، [بعد](phase2/screenshots/vehicle-after.png). الصور High، 960×600، نفس السيارة وخطوات القيادة والكاميرا. لم تستخدم صورًا مولّدة أو نماذج من ألعاب تجارية.

صُححت أدوات الاختبار لقبول query string الذي يضيفه Vite بعد التعديل؛ كان سبب timeout في harness. فحوص الرجوع الكاملة والقياس النهائي تتبع دفعة المؤثرات.

### دفعة مؤثرات السباق

دخان الانجراف الآن يتمدد ويتلاشى عبر alpha وبكثافة مرتبطة بالسرعة، مع أحجام وأعمار مختلفة لجسيمات النيترو والشرارات. كلها في مخزن ثابت من 150 خانة وطلب رسم واحد؛ Low مع تقليل المؤثرات يستخدم 33 خانة فقط. عولج إعادة استخدام الخانات على الجودة المنخفضة، ومسحها عند الإعادة. لهبا العادم additive متحركان وخطوط السرعة أخف، وآثار العجلات المتكررة محفوظة. لم تُضف تمريرة Bloom؛ لا يوجد جهاز GPU لإثبات ميزانيتها، ولا تُسمى الوهجات الموجودة Bloom.

نجحت **27/27 وحدة اختبار، البناء، 4/4 فحوص مؤثرات، و6/6 فحوص المرحلة الثانية**. الدخان وآثار العجلات اختُبرا بقيادة وانجراف فعليين، والنيترو باستهلاك فعلي. اختبار رسم الشرارات يستدعي مؤثر التصادم؛ اختبار Cannon المنفصل يغطي التلامس الفيزيائي. النتائج الكاملة للخمسة مطابقة لـc81bccd عند 60.783333 ثانية للاعب. [المؤثرات](phase2/effects-checks.json)، [السباق والجودة والموارد](phase2/effects-race-checks.json).


## إعادة القياس

```bash
npm run dev -- --port 5173
# مرجع منفصل عند c81bccd على 5191:
GAME_URL=http://localhost:5191 PROFILE_LABEL=before npm run profile
GAME_URL=http://localhost:5173 PROFILE_LABEL=performance npm run profile
npm run test:phase2
```

ناتج `before` يحفظ موضع الكاميرا في `artifacts/phase2/reference-view.json`؛ المقارنات التالية تعيد استخدامه. يجب تشغيل القياسات تسلسليًا لتجنب تنافس المتصفحات على CPU. الصور والنتائج الخام تحفظ في `artifacts/phase2/` ثم تُنسخ الأدلة المختارة إلى التقرير.

اختبار WebKit المحلي لم يعمل بعد تنزيل المحرك: مكتبات النظام ناقصة، وفشل تثبيتها برسالة `su: Authentication failure`. لم تُحاول صلاحيات بديلة. يبقى iOS Safari على جهاز فعلي غير معتمد حتى اختباره.
