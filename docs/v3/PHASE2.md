# Sunset Rush 3.0 — Phase 2

بدأ التنفيذ في 2026-11-08 من `c81bccd` على `feat/sunset-rush-visual-performance`. هذا تقرير مرحلي يُحدّث بعد كل دفعة. لا رفع للفرع، ولا تعديل لـPR #1 أو main، ولا نشر.

## A — الأداء قبل التطوير البصري

أُضيفت وحدة `performance.js` لقياس FPS ومتوسط زمن الإطار وP95/P99 من آخر 300 إطار، مع زمن CPU للمحاكاة وإرسال الرسم. تعرض الواجهة أيضًا draw calls والمثلثات وgeometries/textures/programs وذاكرة JS المستخدمة/حدها والمتبقي منها عندما يوفرها المتصفح. **VRAM المتاحة غير مكشوفة بهذه الواجهات وتبقى null**، ولا تُخلط مع heap.

الجودة: Low/Medium/High/Ultra/Auto، مع الحفاظ على معرّفات الإعدادات القديمة. Auto تستخدم دقة تكيفية من 60% إلى 100% من سقف المستوى، بمتوسط أسي ومهل مختلفة للصعود والنزول وhysteresis. تحديث حجم framebuffer مقنن إلى مرة كل 350ms وبخطوات صغيرة لتجنب إعادة تخصيصه كل إطار. الخيارات 30/60/120 هي ميزانية مستهدفة للتكيف، وليست فرضًا لمعدل أعلى من الشاشة أو ضمانًا له. توجد مفاتيح للظلال وتخفيف المؤثرات والدقة التكيفية.

التحسينات المنفذة:

- تجميع الديكور في خلايا مكانية ذات bounding volumes، بدل مجموعات تمتد عبر الجزيرة كلها.
- InstancedMesh للمباني، مع حدود لكل عنقود؛ Three r128 يعطل frustum culling للمجسمات المتكررة افتراضيًا ولا يحسب حدودها تلقائيًا.
- LOD بعيد للمنافسين في draw call واحد لكل سيارة، مع hysteresis. تفاصيل سيارات اللاعب والخصوم القريبين محفوظة. تحسين شكل الـLOD البعيد ضمن دفعة السيارات التالية.
- خامات Lambert للأجزاء غير المعدنية البعيدة، وإعادة استخدام خامة الأشرعة. بقي طلاء سيارات اللاعب PBR.
- تحديث الظلال بمعدل 24/30/60Hz حسب المستوى، وتعطيلها على Low؛ لا إعادة تخصيص لخريطة الظل إذا لم يتغير حجمها.
- إعادة استخدام المضمار الساحلي عند إعادة السباق بنفس إعداداته، بدل إنشاء هندسته وخاماته مرة أخرى. المسارات القديمة تبقى على مسار إعادة البناء الأصلي للحفاظ على عناصر اللعب القابلة للجمع.

### بيئة القياس وطريقته

Node 24.22.1، Chromium 156.0.8078.79، Linux، ANGLE/Vulkan **SwiftShader برمجي**. لا GPU فعلي ولا iPad أو هاتف فعلي. دقة 960×600، DPR=1، جودة Medium، نفس السيارة والمضمار والكاميرا وبذرة 135، محاكاة ثابتة أثناء القياس وطور الماء صفر.

لكل متغير: 3 تسخينات ثم 20 عينة `render + readPixels(1×1)`، مع طلب تحديث الظل كل مرة. العدادات تشمل تمريرة الظلال. القراءة ضرورية: تجربة `gl.finish` الأولى أعطت زمن إرسال الأوامر فقط فاستُبعدت. P95/P99 من 20 عينة تقديرات خشنة؛ P99 قريب من أكبر عينة. هذه قياسات مقارنة للمشهد البرمجي وليست FPS لعب على جهاز حقيقي.

| القياس المطابق | قبل c81bccd | بعد دفعة الأداء |
| --- | ---: | ---: |
| متوسط الرسم + readback | 491.78 ms | 357.59 ms |
| P95 | 555.40 ms | 480.50 ms |
| P99 | 715.40 ms | 541.70 ms |
| طلبات الرسم، مع الظل | 174 | 117 |
| المثلثات، مع الظل | 66,514 | 28,010 |
| geometries المُحمّلة في لقطة القياس | 126 | 83 |
| textures | 5 | 5 |
| تجهيز إعادة السباق، 5 عينات | 40.4–133.3 ms | 0.5–2.2 ms |

انخفض متوسط الرسم في هذه العينة نحو **27%**. الموارد المحملة تتأثر بالأجزاء المرئية وLOD؛ لا يمثل العدد تقدير VRAM. خلال عينات إعادة السباق بعد التحسين استقرت geometries عند 157 وtextures عند 5؛ كثرة الخلايا تزيد عدد موارد العالم الممكن تحميلها لكنها تقلل الرسم خارج المشهد وتمنع إعادة البناء.

فصل التكلفة قبل التعديل: تعطيل الظل خفّض المتوسط إلى 355.02ms؛ تعطيل الماء معه إلى 346.19ms؛ إخفاء السيارات مع إبقاء الماء إلى 280.79ms؛ نصف الدقة بلا ظل إلى 152.20ms. لذلك عولجت كلفة البكسلات والظلال والخامات/تفاصيل السيارات أولًا. قياس CPU لـ1200 خطوة محاكاة: 77.8ms قبل و85.0ms بعد في هاتين العينتين؛ **لا ندّعي تحسن CPU من هذه النتيجة**، ولم تُعدّل معادلات الفيزياء.

### اختبارات دفعة الأداء

- `npm test`: **21/21**، منها الـ15 السابقة؛ اختبارات جديدة للعدادات وDRS وhysteresis وحدود InstancedMesh وLOD.
- `npm run build`: ناجح؛ يستمر تحذير حزمة Three.js التي تزيد قليلًا على 500KB قبل الضغط.
- `node tests/phase2.mjs`: **6/6**، صفر أخطاء JavaScript/WebGL. تغيير الجودة لا يغير حالة الفيزياء؛ تكرار إعادة السباق والجودة لا يزيد الموارد بعد التسخين؛ Auto خفضت framebuffer استجابة لزمن rAF الحقيقي؛ الإعدادات محفوظة وتناسب عمودي/أفقي.
- سباق كامل مع أربعة منافسين يطابق نتائج المرحلة الأولى بالضبط: **60.783333s**، ثلاث لفات، المركز الأول، ونفس أوقات ومسافات إنهاء الخمسة.
- تُعاد اختبارات المتصفح الـ34 كاملة بعد دفعات الرسوم، إلى جانب اختبارات الإنتاج والتوافق.
